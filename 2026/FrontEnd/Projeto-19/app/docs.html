Primeiros Passos

Requisitos do Sistema

4 GB de RAM, 20 GB livres e processador Dual-Core 64 bits.

Como Instalar

  1. Baixe a imagem ISO.
  2. Use Rufus ou BalenaEtcher.
  3. Reinicie e siga o assistente.

Primeiro Boot

Configure o Wi-Fi, suas preferências e instale as atualizações.

Comandos Essenciais

sudo apt update Atualiza a lista de pacotes.
sudo apt install nome Instala um programa.
ls -la Lista os arquivos.
cd pasta Abre outra pasta.

Perguntas Frequentes

O Kitty Linux é gratuito?

Sim, ele é gratuito e open-source.

Funciona em computadores antigos?

Sim, o sistema foi desenvolvido para ser leve.

Como atualizar o sistema?

Use o gerenciador de atualizações ou o terminal.
